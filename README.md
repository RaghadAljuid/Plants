# Plant Care Reminder App🪴

## Purpose

The **Plant Care Reminder App** is designed to help plant owners manage the care of their plants efficiently by setting personalized reminders for each plant. This app allows users to track and complete plant care tasks, ensuring that their plants receive the attention they need on time.

## Features

- **Add Plant Reminders**: Users can set reminders with specific care details for each plant, including watering, pruning, and other necessary tasks.
- **Update Plant Information**: The app allows users to update plant details and care reminders as needed, providing flexibility in case of changes.
- **Delete Plant Reminders**: When a plant no longer needs care or is removed, users can delete the corresponding reminders.
- **View Daily Care Reminders**: Users can see a list of all daily care tasks for their plants, ensuring that no task is missed.
- **Mark Reminders as Done**: After performing a care task for a plant, users can mark the reminder as complete, helping to track their progress.
- **Track Progress**: The app tracks the progress of plant care and provides a summary of completed tasks.
- **Confirmation on Completion**: Once all reminders for a particular plant are completed, users receive a confirmation message.

## Usage

1. **Create New Reminders**: Add a plant and specify the care tasks with due dates.
2. **Manage Existing Reminders**: Update, delete, or view reminders at any time.
3. **Track Care Progress**: Mark tasks as done and view a summary of your progress.
4. **Get Notifications**: Receive reminders for daily tasks and get a confirmation when everything is completed.
